🎮 Игра «Виселица» на Java

Добро пожаловать в проект «Виселица» (Hangman) — консольную реализацию классической игры по угадыванию слов, написанную на Java.

Программа загружает случайное слово из внешнего словаря, обрабатывает ввод игрока, ведет учет ошибок и динамически отображает текущее состояние загаданного слова.

Для того что бы начать игру - нажмите 1
Для того что бы выйти из игры - нажмите 2

6 - общее количество попыток
Каждая ошибка уменьшает количество попыток на 1, и так же показывает состояние после неправильной буквы
Если ввести использованную букву, то количество попыток не уменьшиться

Игра будет продолжаться пока пользователь не введет цифру 2

! Разрешено вводить только буквы русского алфавита, другие символы не будут влиять на состояние виселицы !
